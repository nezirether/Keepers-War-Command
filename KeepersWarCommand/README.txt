Keepers War Command 1.7.0 (UI 2.0)
World of Warcraft: Forever 1.60.1 | Interface 16001 | Private test

Exit WoW. Back up the old addon folder and SavedVariables, then replace
the addon folder in Interface/AddOns. Keep your SavedVariables.
Open War Command with /kwc, /kt or /keepers.
The native Trogdor minimap button also opens War Command. Right-click for
Preferences, or drag it around the minimap to move it.

Shared guild features require a verified guild and compatible clients.
Guild Services sharing turns on once for the active character after guild and
roster verification. You can turn it off at any time in Preferences.
Offline recovery requires an eligible officer holding the records.
Multiplayer behavior and some Forever APIs still need live testing.

Support: https://github.com/nezirether/Keepers-War-Command/issues
