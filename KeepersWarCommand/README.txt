KEEPERS OF TROGDOR — WAR COMMAND v1.4.0
GUILD RELEASE | World of Warcraft: Forever | Interface 16001

INSTALL
1. Exit the game.
2. Back up and replace the existing Interface/AddOns/KeepersWarCommand folder.
3. Keep your SavedVariables (KWCDB) to preserve settings and records.
4. Launch the game and type /kt to open War Command.

FEATURES
- Command dashboard and streamlined CTA / bounty detail views
- CTA priority: Low, Normal, High, Urgent
- Auto Scout (on by default for new settings), manual reports and guild sighting sync
- War Room, scout intelligence, and after-action reports
- PvP leaderboard, achievements, recruitment, guild alerts
- Guild-wide CTA/bounty deletion by creator, War Council, or Warchief
- Deletion records synchronize to other compatible guild clients, including on later login when peers are available
- Optional Overlord Forever / War Effort Scout detection

NOTES
- All guild members should use v1.4.0 for deletion synchronization.
- Deleted entries cannot be restored through the addon UI.
- Cross-guild synchronization is not supported.
- Offline synchronization requires a compatible guildmate online with deletion history.
- War Room scouting and after-action report features may have different sync capabilities; do not assume all data is shared.

SUPPORT
Report bugs to guild leadership with screenshot, character name, steps to reproduce, and any Lua error text.
