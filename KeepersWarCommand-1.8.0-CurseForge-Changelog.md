# Keepers War Command 1.8.0 Alpha

## New in this build

- Bounty alerts now include a **Report Sighting** button that opens a form with the target and observed zone already filled in.
- When you submit a sighting, online guildmates running this build see the target, location, and reporter in their local chat.

## Also included in 1.8

- Guild Records has a more readable layout and lifetime rankings. Sharing is on by default and can be turned off from Guild Records.
- The Death Leaderboard shows **Total Deaths**, **Deaths to Players**, **World PvP Estimate**, and **Battlegrounds**. The World PvP figure is an estimate based on reported battleground and player-death totals.
- The PvP Leaderboard uses Honorable Kills for its lifetime, World PvP, and Battleground views.

## Bug fixes

- Live bounty sightings announce once even when a compatible client receives both message formats. Offline recovery restores sighting records quietly.
- Bounty and Call to Arms recovery restores more details, responses, and activity from an eligible officer's cache.
- Queued synchronization whispers skip guildmates marked offline and pause after a terminal send failure.
- Raid Attendance pull replies must match the authorized request and still require confirmation before replacing records.

Built for **WoW Forever 1.60.1**. Live multiplayer verification is pending.
